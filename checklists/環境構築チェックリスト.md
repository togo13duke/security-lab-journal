# 環境構築チェックリスト

## 結論

フェーズ0の環境はシンプルでよい。複雑な攻撃用ディストリビューションより、日常的にログを残せる作業環境を優先する。

## 必須

- [ ] Gitが使える
- [ ] エディタでMarkdownを書ける
- [ ] ターミナルを日常操作できる
- [ ] Python 3が使える
- [ ] Python仮想環境を作れる
- [ ] Wiresharkをインストール済み
- [ ] ローカル検証用ディレクトリを用意済み
- [ ] 学習ログをGitでcommitできる

## あるとよい

- [ ] ローカルVMまたはDocker環境
- [ ] Burp Suite Community Edition
- [ ] jq
- [ ] ripgrep
- [ ] tree
- [ ] tmux

## セキュリティ設定

- [ ] 個人用・学習用の認証情報を分離している
- [ ] 秘密情報をGitに入れないルールを決めている
- [ ] `.gitignore` を用意している
- [ ] ラボ用ブラウザプロファイルを分けている
- [ ] 許可されていない対象にツールを向けない運用ルールを書いた

## 最小構成

時間がない場合、最小構成はこれで足りる。

- ターミナル
- Git
- Python 3
- Markdownエディタ
- ブラウザ
- Wireshark

Kali Linuxはフェーズ0では必須ではない。必要になってから入れる。
