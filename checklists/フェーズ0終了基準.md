# フェーズ0終了基準

## 結論

フェーズ0は「次に進みたい」ではなく「基礎動作を説明し、記録し、再現できる」で完了とする。

## 必須基準

- [ ] 合法範囲と禁止事項を自分の言葉で説明できる
- [ ] ターミナルで日常的なファイル操作ができる
- [ ] パイプ、リダイレクト、標準入力・標準出力・標準エラーを説明できる
- [ ] Gitで日次ログを管理できる
- [ ] TCP/IP、DNS、HTTPの基本フローを説明できる
- [ ] Wiresharkで自分の通信を観察し、何が起きているか説明できる
- [ ] Pythonでファイル処理とログ整形の小スクリプトを書ける
- [ ] 許可された演習環境で学習ログを5本以上残した
- [ ] 3か月分のweekly-reviewが最低8本ある

## 成果物基準

- [ ] コマンドチートシート
- [ ] HTTPチートシート
- [ ] Git運用メモ
- [ ] Python小スクリプト3本
- [ ] ラボノート5本以上
- [ ] フェーズ0振り返り1本

## 不合格パターン

- ツールの実行結果だけ残っていて、なぜそうなったか説明がない。
- CTFの答えだけ集めている。
- Git履歴がない。
- 許可範囲の記録がない。
- ネットワークやHTTPの説明が曖昧なままWeb脆弱性に進もうとしている。

## 次フェーズへ進む判断

次の質問に即答できるならフェーズ1へ進んでよい。

1. この検証対象はなぜ合法か。
2. この通信はどのプロトコルで、どの宛先に向かっているか。
3. このログから何が事実で、何が推測か。
4. 同じ結果をもう一度再現するには何をすればよいか。
5. 失敗した場合、どこから切り分けるか。
