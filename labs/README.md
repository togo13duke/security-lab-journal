# Labs

## 結論

このディレクトリには、許可された演習の記録だけを置く。手順そのものより、観察・仮説・結果・学びを残す。

## 許可対象

- ローカルVMまたはローカルコンテナ
- 自作Webアプリ
- OverTheWire Bandit
- PortSwigger Web Security Academy
- その他、利用規約で演習が明示的に許可されている環境

## 禁止

- 実在サービスのスキャン結果
- 認証情報、トークン、Cookie、秘密鍵
- CTFフラグ、パスワード、解答そのもの
- 第三者のログ、個人情報、機密情報

## 推奨ファイル名

```text
YYYY-MM-DD_topic.md
```

例：

```text
2026-06-03_bandit-file-permissions.md
2026-06-10_http-status-codes.md
```

## 記録の粒度

1課題につき1ファイル。長くてもよいが、必ず次を含める。

- 目的
- 対象環境
- 前提条件
- 観察
- 試したこと
- 結果
- 学び
- 次に調べること
