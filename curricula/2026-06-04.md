### 0. 準備 5分

- 今日の対象を「自分のPC上のローカルHTTPサーバ」だけに限定する。
- 外部サイト、公開IP、他人の環境には一切触らない。
- 成果物ファイル名を決める。

```text
labs/2026-06-04_http-local-observation.md
```

### 1. 環境確認 10分

次を確認する。

```sh
git status
python3 --version
curl --version
pwd
```

記録する観点：

- Gitでログを残せるか。
- Python 3が使えるか。
- curlでHTTPリクエストを観察できるか。
- 作業ディレクトリがリポジトリ内か。

### 2. ローカルHTTPサーバ作成 15分

ローカルだけで観察対象を作る。

```sh
mkdir -p labs/sandbox/http-demo
printf '<!doctype html><title>Phase0 HTTP</title><h1>Hello HTTP</h1>\n' > labs/sandbox/http-demo/index.html
python3 -m http.server 8000 --directory labs/sandbox/http-demo
```

別ターミナルで確認する。

```sh
curl -v http://127.0.0.1:8000/
```

観察する項目：

- request line：`GET / HTTP/1.1`
- response status：`200 OK`
- header：`Content-Type`、`Content-Length` など
- body：HTML本文
- 127.0.0.1 がローカル宛先であること

### 3. HTTP読解 20分

`curl -v` の出力から、次の3行を自分の言葉で書く。

```text
これは何か：
なぜ必要か：
手元でどう確認したか：
```

対象概念：

- HTTP request
- HTTP response
- method
- status code
- header
- body
- localhost / 127.0.0.1

### 4. 失敗ケース観察 15分

存在しないパスを叩く。

```sh
curl -v http://127.0.0.1:8000/not-found
```

記録する観点：

- 成功時と失敗時でstatus codeがどう変わったか。
- bodyやheaderに違いがあるか。
- どこまでが事実で、どこからが推測か。

### 5. ラボノート作成 20分

`templates/lab-note.md` の型に沿って、以下を必ず書く。

- 目的：ローカルHTTP通信のrequest/responseを読む。
- 対象環境：自分のPC、127.0.0.1、Python標準HTTPサーバ。
- 許可根拠：自分のローカル環境。
- 範囲：`127.0.0.1:8000` のみ。
- 観察：`200 OK` と `404` の差。
- 試したこと：実行したコマンド。
- 結果：読めたHTTP要素。
- まだ不明なこと：最低1つ書く。
