# フェーズ0｜0〜3か月：土台作り

このリポジトリは、合法範囲でセキュリティ基礎を積むためのフェーズ0参考資料置き場。
目的は、攻撃テクニックを急ぐことではなく、2年間伸び続けるための基礎体力を作ること。

## フェーズ0の結論

0〜3か月で作るべき土台は次の5つ。

1. 合法範囲を判断できること
2. Linux・シェル・Gitを毎日使えること
3. TCP/IP・DNS・HTTPの基本挙動を説明できること
4. Pythonで小さな自動化を書けること
5. 学習ログ、検証ログ、失敗ログを残せること

## 進め方

- 月〜金：30〜60分。Linux、ネットワーク、Python、Gitの小課題を回す。
- 土日：2〜3時間。週の復習、ログ整理、1つの小ラボを完了する。
- 迷ったら「公式ドキュメント → 手元で再現 → 自分の言葉で記録」の順に戻る。

## やらないこと

- 許可のない外部ホストをスキャンしない。
- 他人のアカウント、ネットワーク、Webアプリに触らない。
- マルウェア、フィッシング、認証回避、権限昇格の実運用手順を集めない。
- ツール名だけ覚えて理解した気にならない。
