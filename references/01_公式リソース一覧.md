# 公式リソース一覧

## 結論

フェーズ0では、二次情報より公式・一次情報を優先する。動画やブログは補助に留め、最終的な確認先を公式ドキュメントに固定する。

## 基礎ツール

| 領域 | 優先リソース | 使い方 |
| --- | --- | --- |
| シェル・CLI | The Missing Semester of Your CS Education | Shell、Git、データ処理、デバッグの導入に使う |
| Bash | GNU Bash Reference Manual | シェル挙動の最終確認に使う |
| Git | Pro Git book / git-scm docs | commit、branch、merge、rebase、diffの理解に使う |
| Python | Python公式チュートリアル | 小さな自動化、ログ処理、HTTP処理の基礎に使う |

## ネットワーク・Web

| 領域 | 優先リソース | 使い方 |
| --- | --- | --- |
| HTTP | MDN Web Docs HTTP | HTTPメソッド、ステータスコード、ヘッダ、Cookieの理解に使う |
| パケット解析 | Wireshark User's Guide | pcap読解、表示フィルタ、TCP/HTTP確認に使う |
| ネットワーク探索 | Nmap Reference Guide | 自分のローカル環境だけで、オプション意味の確認に使う |

## セキュリティ基礎

| 領域 | 優先リソース | 使い方 |
| --- | --- | --- |
| リスク管理 | NIST Cybersecurity Framework 2.0 | セキュリティを「攻撃技術」ではなくリスク管理として捉える |
| Webセキュリティ | OWASP Web Security Testing Guide | Web検証の分類と報告観点を知る |
| Web演習 | PortSwigger Web Security Academy | 許可されたラボだけでWeb脆弱性の概念を学ぶ |
| Linux演習 | OverTheWire Bandit | コマンドライン、権限、ファイル操作の訓練に使う |
