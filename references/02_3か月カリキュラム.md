# 3か月カリキュラム

## 結論

最初の3か月は「広く浅く」ではなく、「毎日使う基礎を深く」に振る。特にLinux、Git、ネットワーク、Python、記録習慣を優先する。

## 1か月目：作業環境とLinux基礎

### 到達目標

- ターミナルでファイル操作、検索、パイプ、リダイレクトを使える。
- Gitで日次ログをcommitできる。
- 自分の学習ログをMarkdownで残せる。

### 学ぶ項目

- `pwd`, `ls`, `cd`, `cp`, `mv`, `rm`, `mkdir`, `touch`
- `cat`, `less`, `head`, `tail`, `wc`, `sort`, `uniq`, `cut`, `grep`, `find`
- パイプ、リダイレクト、標準入力、標準出力、標準エラー
- ファイル権限、ユーザー、グループ、パス、環境変数
- Git: `init`, `status`, `add`, `commit`, `diff`, `log`, `branch`

### 成果物

- `daily-log` を最低20日分
- コマンドチートシート1枚
- Gitで追跡された学習ログ

## 2か月目：ネットワークとWebの基礎

### 到達目標

- TCP/IP、DNS、HTTPの基本的な流れを説明できる。
- Wiresharkで自分の通信を観察できる。
- HTTPリクエストとレスポンスの構造を読める。

### 学ぶ項目

- IPアドレス、ポート、TCP/UDP、3-way handshake
- DNS名前解決
- HTTPメソッド、ステータスコード、ヘッダ、Cookie、セッション
- TLSの役割。ただし暗号の詳細実装には深入りしない。
- Wiresharkの表示フィルタ

### 成果物

- DNS解決の観察メモ
- HTTPリクエスト/レスポンス読解メモ
- Wiresharkで観察したpcapの説明メモ

## 3か月目：Python自動化と安全な演習

### 到達目標

- Pythonでファイル処理、JSON処理、HTTP取得、ログ整形ができる。
- OverTheWire Banditの序盤を、解答ではなく学びとして記録できる。
- PortSwigger Academyの基礎ラボを、概念中心に記録できる。

### 学ぶ項目

- Python: 変数、関数、例外、ファイル、標準ライブラリ、仮想環境
- `json`, `csv`, `pathlib`, `subprocess`, `urllib` または `requests`
- ログの整形、Markdown生成
- 演習ログの書き方

### 成果物

- Python小スクリプト3本
- Bandit学習ログ5〜10本
- Web Security Academy基礎ラボの概念メモ3〜5本
- フェーズ0終了レビュー

## リスク

- ツールを触っただけで理解した気になる。
- CTFの解答収集に流れる。
- 記録を残さず、3か月後に何も再利用できない。
- Linuxとネットワークを飛ばしてWeb脆弱性に進み、説明不能になる。

## 代替案

時間が少ない場合は、Web演習を削ってLinux・Git・Python・HTTPに集中する。フェーズ0では派手な成果より基礎の定着を優先する。
