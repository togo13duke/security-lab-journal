# 基礎概念チートシート

## 結論

フェーズ0で暗記すべきなのはツール名ではなく、コンピュータとネットワークが何をしているかを説明する言葉。

## Linux / Shell

- シェル：ユーザーの入力を解釈し、プログラムを起動するインターフェース。
- 標準入力：プログラムに入るデータの流れ。
- 標準出力：プログラムが通常結果を出す流れ。
- 標準エラー：エラーや診断情報を出す流れ。
- パイプ：あるコマンドの出力を次のコマンドの入力に渡す仕組み。
- 権限：読み取り、書き込み、実行をユーザー・グループ・その他に分けて制御する仕組み。

## Git

- commit：ある時点の変更を意味付きで保存した単位。
- branch：履歴の分岐線。
- diff：変更前後の差分。
- staging area：次のcommitに含める変更を一時的に置く場所。

## Network

- IPアドレス：ネットワーク上の宛先識別子。
- ポート：同一ホスト内のアプリケーション入口。
- TCP：到達性と順序を管理する通信プロトコル。
- UDP：軽量で順序保証しない通信プロトコル。
- DNS：ドメイン名をIPアドレスなどに解決する仕組み。
- TLS：通信経路上の盗聴・改ざんを防ぐための暗号化層。

## HTTP

- request：クライアントからサーバへの要求。
- response：サーバからクライアントへの応答。
- method：GET、POSTなど、要求の意図を表す。
- status code：200、301、404、500など、応答結果を表す番号。
- header：通信のメタデータ。
- body：実データ部分。
- cookie：ブラウザ側に保存され、リクエスト時に送られる小さなデータ。
- session：サーバ側でユーザー状態を管理する仕組み。

## Security

- 脆弱性：想定外の操作や条件で、機密性・完全性・可用性に悪影響を与える弱点。
- 攻撃面：外部から触れる入口の集合。
- 最小権限：必要最小限の権限だけを与える原則。
- ログ：後から事実確認するための記録。
- 再現性：同じ条件で同じ結果を得られる性質。
